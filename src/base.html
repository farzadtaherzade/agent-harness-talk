حلقهٔ ReAct: فکر ← عمل ← مشاهده

هارنس این حلقه را اجرا می‌کند: هر «عمل» پیش از اجرا از فیلتر گاردریل عبور می‌کند و نتیجهٔ آن به حافظه بازمی‌گردد.

01
فکر Thought
مدل هدف را می‌شکند و طرح‌وارهٔ عمل را می‌نویسد. هارنس این متن را به ساختار JSON معتبر تبدیل می‌کند.
{"thought": "ابتدا لاگ را جست‌وجو کن"}
02
عمل Action
هارنس عمل را در sandbox و از طریق ابزار مجاز اجرا می‌کند؛ سیاست‌ها پیش از اجرا بررسی می‌شوند.
{"tool": "shell", "args": {"cmd": "pytest -q"}}
03
مشاهده Observation
خروجی ابزار به حافظه بازگردانده می‌شود و حلقه تا رسیدن به پاسخ یا سقف بودجه تکرار می‌شود.
{"observation": "exit_code=1, 1 failed"}

04 — practice

معماری هارنس در کد و اجرای زنده

روی «اجرای هارنس» بزنید: خطاها رهگیری می‌شوند، ابزارها فراخوانی می‌شوند و محدودیت‌های ایمنی اعمال می‌شوند.

harness.py python 3.11 
"""Reference architecture of an agent harness."""
from dataclasses import dataclass, field

@dataclass
class Guard:
    allow: set = field(default_factory=set)
    def check(self, action: dict) -> None:
        if action["tool"] not in self.allow:
            raise PermissionError(action["tool"])
        if action.get("destructive"):
            raise PermissionError("human approval")

@dataclass
class Harness:
    llm: Any
    tools: dict
    memory: list = field(default_factory=list)
    limits: dict = field(default_factory=lambda: {"steps": 8, "tokens": 32_000})
    guard: Guard = field(default_factory=Guard)
    def run(self, task: str) str:
        for step in range(self.limits["steps"]):
            thought = self.llm.think(task, self.memory)
            action  = self.parse(thought)      # JSON -> tool call
            self.guard.check(action)         # policy + permission
            try:
                obs = self.dispatch(action)   # sandboxed execution
            except ToolError as exc:
                obs = {"error": str(exc)}  # recover, don't crash
            self.memory.append({"step": step, "obs": obs})
        return self.llm.summarize(self.memory)

جمع‌بندی: چه چیزی یک هارنس را تولیدی می‌کند

0 ابزار متصل و قابل فراخوانی search · code · shell · db · api · browser · fs · test
0 لایهٔ گاردریل سیاست · مجوز و تأیید انسانی · بودجه
0 گام در یک چرخهٔ ReAct فکر · عمل · مشاهده · بازخورد
0 قابلیت ردیابی هر فراخوانی لاگ ساختاریافته + replay
  • ✓گاردریل چندلایههر عمل پیش از اجرا از فیلتر سیاست، مجوز و بودجه عبور می‌کند.
  • ✓محدودیت‌های سختسقف مرحله، سقف توکن و timeout تا ایجنت نتواند در حلقه گیر کند.
  • ✓ایزوله‌سازی اجرااجرای کد ابزار در sandbox، بدون دسترسی مستقیم به سیستم.
  • ✓حافظهٔ دو لایهحافظهٔ کوتاه‌مدت برای حلقه، حافظهٔ بلندمدت با بازیابی معنایی.
  • ✓مدیریت خطاخطا داده است نه استثنا: رهگیری، بازآزمایی و مسیر جایگزین.
  • ✓ارزیابی و بازپخشهر اجرا قابل بازپخش است تا تغییرات کیفیت سنجیده شود.
مدل، موتور است. هارنس، خودرو است. بدون هارنس، شما فقط یک قطعهٔ گران‌قیمت دارید.
ایجنت، رفتاری است که هارنس ممکنش می‌کند؛ و هر قطعه یک اهرم است: هرچه ابزار، دسترسی یا بودجه بازتر، استقلال بیشتر و ریسک بیشتر.
